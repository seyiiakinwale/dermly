# Dermly — AI Skincare Companion for Men (frontend prototype)

Mobile-first static prototype. No backend, mock data in `app.js`.

Open `index.html` directly, or deploy to Vercel as a static site.

- 18 MVP screens + Skin Journey home, XP/levels, streaks + shields, quests, achievements
- Design system in `design-system.md`, tokens in `styles.css`
- Icons: Lucide via CDN. Product photos: Unsplash.
- State persists to `localStorage dermly_full`.
